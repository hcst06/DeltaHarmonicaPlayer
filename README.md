# 三角洲口风琴播放器

一个面向 Windows 的本地口风琴辅助播放器。它可以读取 MIDI、把数字简谱转换为 MIDI，也可以使用 Spotify Basic Pitch 模型从音频中提取音符，再通过 Windows `SendInput` 按照《三角洲行动》口风琴的键位演奏。

> [!WARNING]
> 自动化键盘或鼠标输入可能违反游戏规则，并可能带来封禁等风险。本项目不提供反检测、绕过反作弊或修改游戏内存的功能；是否使用以及产生的后果由使用者自行承担。本项目与腾讯、琳琅天上、Spotify 均无隶属或背书关系。

## 主要功能

- 曲库管理：导入 `.mid` / `.midi`，点击歌曲即可快速切换。
- 轨道选择：按“原始轨道 + MIDI 通道”列出旋律候选，自动跳过 MIDI 第 10 通道的打击乐，也可手动改选。
- 游戏演奏：`F9` 立即开始，`F10` 随时停止并松开全部按键；界面按钮提供 3 秒切回游戏倒计时。
- 演奏设置：速度可在 `0.50×–1.50×` 之间调整；保持 MIDI 原调，无法映射到游戏音域的音符会被舍弃并显示数量。
- 简谱转 MIDI：支持连续数字、升降音、上下八度、休止、延音和减时。
- AI 音频扒谱：支持 MP3、WAV、FLAC、OGG，最长 5 分钟；模型和页面资源从本地加载，应用代码不会把音频上传到云端。

## 下载与运行

1. 从 GitHub([Releases](https://github.com/hcst06/DeltaHarmonicaPlayer/releases/tag/v1.0.0)) 下载“便携版 ZIP”。
2. 完整解压到有足够空间、允许写入的磁盘目录。不要只复制其中的 EXE；`AudioTranscriber` 模型目录是音频扒谱所必需的。
3. 运行 `App\DeltaHarmonicaPlayer.exe`，并接受 Windows 的管理员权限提示。
4. 在游戏内打开口风琴后，回到播放器选择歌曲和轨道。按“开始演奏”后有 3 秒切回游戏，或直接在游戏中按 `F9`。
5. 按 `F10` 可紧急停止。若热键被其他程序占用，播放器会提示，此时仍可使用界面按钮。

播放器请求管理员权限，是为了在游戏也以较高权限运行时仍能发送输入；这并不保证所有游戏版本或反作弊环境都会接受模拟输入。Windows 10/11 通常已安装 Microsoft Edge WebView2 Runtime；如果缺少它，只有“音频转 MIDI”功能会提示前往微软官方下载页。

便携版请保持以下结构：

```text
三角洲口风琴播放器/
├─ App/
│  ├─ DeltaHarmonicaPlayer.exe
│  └─ AudioTranscriber/
├─ Songs/
├─ README.md
├─ LICENSE
├─ THIRD-PARTY-NOTICES.txt
└─ DOTNET-THIRD-PARTY-NOTICES.txt（构建环境提供时）
```

`Songs` 与 `App` 必须位于同一级目录。导入或生成的 MIDI 会保存在 `Songs` 中；WebView2 的本地缓存保存在同级 `WebView2Data` 中，退出程序后可删除缓存。

## 音频转 MIDI（AI 扒谱）

点击“音频转 MIDI”，选择或拖入音频，填写曲名并开始识别。可选三种模式：

- 标准：速度与识别量的常用平衡，推荐先用。
- 干净：提高筛选强度，减少鼓点、伴奏等杂音造成的误音。
- 灵敏：保留更多候选音符，也更容易出现多余音符。

“只保留游戏口风琴能演奏的音域”默认开启。识别完成后会生成两个可选轨道：

- `AI Melody`：从同时出现的音符中抽取单声部旋律，播放器默认选择。
- `AI All Notes`：保留全部识别结果，便于比较或后续在 MIDI 编辑器中修正。

音频解码由 WebView2/Windows 媒体组件完成，因此少数编码特殊的同扩展名文件仍可能打不开。AI 扒谱不会百分之百准确；人声或单件乐器、主旋律清晰且伴奏较少的片段效果通常更好。完整歌曲建议先做人声/乐器分离，并在演奏前试听和修正生成的 MIDI。转换优先使用 WebGL，无法使用时退回 CPU，长音频可能需要较长时间。

## MIDI 与音轨

点击“添加 MIDI”可一次导入多个 `.mid` / `.midi` 文件；也可以把文件直接复制进 `Songs` 后点击“刷新”。程序会保留文件中的节拍变化，并按原始轨道和通道拆分候选旋律。

口风琴一次只能演奏一个音。若所选轨道包含和弦，播放器会在同一时刻的音符中选取一个较高音作为旋律；复杂编曲建议选择音符较少、旋律更清晰的轨道。

## 简谱转 MIDI

点击“简谱转 MIDI”，设置曲名、调号和 BPM，然后输入数字简谱：

- `1–7`：音符，连续书写或空格分组均可。
- `0`：休止一拍。
- `#4` / `b7`：升音 / 降音。
- `1'` 或 `1̇`：高八度；`1,` 或 `1̣`：低八度。
- `-`：把前一个音延长一拍；`/`：把前一个音缩短一半。
- `|`：小节线，可省略。

例如：

```text
1'1'1'1'6 56542 | 422422 55655
```

## 游戏键位映射

| 音符 | 游戏按键 |
| --- | --- |
| `1 2 3 4 5 6 7 高音1` | `Z X C V B N M ,` |
| 降八度 | 鼠标左键 |
| 升半音 | 鼠标中键 |
| 升八度 | 鼠标右键 |

鼠标修饰键只在对应音符发声期间保持按下。由于游戏更新、用户自定义键位或输入法状态都可能影响结果，使用前请先在安全场景短暂测试。
