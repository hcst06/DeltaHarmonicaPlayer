# 三角洲口风琴播放器

一个面向 Windows 的本地 MIDI 播放器，直接通过 `SendInput` 映射《三角洲行动》口风琴按键，不依赖 AutoHotkey。

## 操作

- 左侧单击歌曲即可快捷切换。
- 右侧可按“原始轨道＋MIDI 通道”选择旋律，并调整演奏速度。
- 点击“添加 MIDI”会复制到统一曲库；直接放进曲库后可点“刷新”。
- 点击“音频转 MIDI”可在本机离线识别 MP3/WAV/FLAC/OGG，并自动加入曲库。
- 点击“简谱转 MIDI”可粘贴数字简谱，生成后会自动加入并选中。
- `F9` 在当前窗口立即开始演奏。
- `F10` 在任意时刻停止并松开全部按键。
- 点击“开始演奏”会倒计时 3 秒，便于切回游戏。

音频扒谱会同时生成 `AI Melody`（推荐旋律）与 `AI All Notes`（完整识别）轨道。完整使用说明、构建方法和第三方许可证见仓库根目录的 `README.md`、`BUILD.md` 与 `THIRD-PARTY-NOTICES.txt`。

## 映射

- `1 2 3 4 5 6 7 高音1` → `Z X C V B N M ,`
- 鼠标左键 → 降八度
- 鼠标中键 → 升半音
- 鼠标右键 → 升八度

程序优先保持 MIDI 的原调和原八度；需要低八度时会正常使用鼠标左键。鼠标修饰键只在对应音符发声期间按住。

## 简谱输入

- 连续或空格分组的 `1–7` 都可以，`0` 表示休止。
- `#4` / `b7` 表示升降音。
- `1'` 或 `1̇` 表示高八度；`1,` 或 `1̣` 表示低八度。
- `-` 延长前一个音一拍，`/` 把前一个音缩短一半，`|` 是可忽略的小节线。
- 示例：`1'1'1'1'6 56542 | 422422 55655`

## 风险

自动按键和鼠标输入可能违反游戏规则并导致封禁。程序不提供反检测功能，请勿在对局中使用。
